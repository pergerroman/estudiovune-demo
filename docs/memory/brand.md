## Identidad visual

La documentación registra una paleta de celeste, crema, tonos oscuros, marrón,
naranja y verde. Los valores vigentes deben comprobarse en `css/scroll.css` y
`proyect/brand.md`.

El lenguaje visual incluye collage, degradados, tarjetas tipo post-it, ventana de archivo y composiciones de carácter manual.
